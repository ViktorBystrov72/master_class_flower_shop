## Дальнейшая публикация

Перед следующей публикацией повторно прочитать `.agents/skills/layero/SKILL.md`, при необходимости `.agents/skills/layero-content-rules/SKILL.md`. В production сервер требует `OWNER_CODE_HASH` в серверном окружении. Он уже настроен для этого проекта. При смене кода получить новый хеш через `hashCode()` из корневого `pass.txt` и передать в настройки этого проекта; не выводить код или хеш в чат, не копировать идентификатор `.layero/project.json` пекарни. `.env.example` удалён по просьбе владельца; локально никакие переменные не нужны.

Хранение по явному выбору владельца — только в памяти процесса. При cold start, остановке или новой публикации все заявки, сессии и правки каталога сбрасываются. Публичный сайт проверен. Сохранение заявок после cold start не предусмотрено выбранным способом хранения; повторную публикацию только ради проверки сброса не выполняли.
