# 04. Данные и безопасность

Хранить позиции витрины, заявки и их состав в памяти серверного процесса, как в образце `bakery-layero` (https://bakery-layero.layero.app/). Это явный выбор владельца от 10.10.2026.

SQLite, PostgreSQL, Cloudflare D1, внешние базы и платные сервисы для этого задания не подключать.
Пока сервер работает, данные доступны после обновления страницы и повторного открытия сайта.
После перезапуска, холодного старта, простоя с остановкой процесса или новой публикации заявки, правки каталога и серверные сессии сбрасываются; каталог снова получает стартовый набор.
Агент обязан описать это поведение в README и итоговом отчёте, не обещать постоянное хранение.

Черновик выбора сохраняется в браузере посетителя и не является подтверждённой заявкой.
Номер заявки возвращать только после успешного добавления заявки и всех её строк в серверное хранилище текущего процесса.

На сервере:  

1. Сверять каждую позицию с витриной, доступностью и остатком.
2. Пересчитывать сумму по актуальным ценам. Плату за доставку считать только если она есть у темы.
3. Сохранять заявку и её состав; возвращать номер только после успешного добавления в память сервера.
4. Не отдавать посетителю список заявок и чужие контакты.
5. Разрешать изменение позиций и статусов только владельцу с действующей серверной сессией после входа по коду из `pass.txt`.

Контакты из заявок видит только владелец. Внешние системы подключай, только если человек их назвал. Не подписывай сайт как учебный.
