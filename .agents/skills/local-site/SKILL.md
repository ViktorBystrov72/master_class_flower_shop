# Локальный запуск

Сайт лежит в `site/`. Корень набора не запускай. Сервер оставь работать и в ответ в чат вставь адрес из вывода команды кликабельной ссылкой. Обычно это http://localhost:3000/. Не подставляй адрес наугад и не публикуй на Layero только чтобы посмотреть сайт.

## Система

Определи систему сам. На Windows `$env:OS` или `ver` содержат `Windows_NT`. На macOS `uname -s` печатает `Darwin`. На Linux `uname -s` печатает `Linux`. Команды бери только после этой проверки.

Если `node -v` уже 20 или новее и `npm -v` отвечает, Node.js не ставь. Иначе поставь Node.js 22 LTS и продолжи в новом сеансе терминала, чтобы `node` и `npm` были в PATH:

- **Windows.** `winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements`. Если `winget` нет, скачай установщик LTS с https://nodejs.org/ и запусти его с добавлением в PATH.
- **macOS.** Если есть Homebrew: `brew install node`. Если нет, поставь установщик LTS с https://nodejs.org/.
- **Linux.** Поставь Node.js 22 LTS с https://nodejs.org/. После `apt install nodejs` снова проверь `node -v`: версия ниже 20 не подходит.

## Запуск

Из `site/` выполни `npm install`, если нет `node_modules` или изменился `package.json`. Затем запусти сервер и дождись строки, что он готов:

```bash
cd site
npm install
npm run dev
```

Если порт занят, возьми адрес, который напечатал сервер, либо запусти `npm run dev -- --port 3001` и отдай этот адрес. Не проси человека ставить пакеты и не проси его самой вводить эти команды.

Сервер не останавливай, пока человек сам не попросит. Остановка во всех системах: Ctrl+C в том терминале, где он запущен.
